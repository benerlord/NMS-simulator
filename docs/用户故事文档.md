## 1. 概述

### 1.1 用户角色

| 角色 | 描述 |
|------|------|
| **测试工程师** | 使用模拟工具测试 MindOps 插件的数据采集功能 |
| **开发工程师** | 维护和扩展模拟工具的功能 |
| **运维人员** | 负责工具的部署和配置 |

### 1.2 术语定义

| 术语 | 说明 |
|------|------|
| **NMS** | 网络管理系统（Network Management System），指 ManageOne、eSight 等网管系统 |
| **插件** | MindOps 采集纳管模块中的数据采集插件 |
| **模拟工具** | 本项目开发的网管系统模拟工具 |
| **OID** | 对象标识符（Object Identifier），SNMP 协议中用于标识管理对象的标识符 |
| **Trap** | SNMP 协议中的一种消息类型，用于代理主动向管理站发送告警信息 |
| **Topic** | Kafka 消息队列的逻辑分类 |
| **拓扑图** | 用于表示设备和设备间关系的图形化结构 |
| **设备节点** | 拓扑图中表示一个设备的矩形或图标 |
| **连线** | 拓扑图中表示两个设备间关系的线条 |
| **DN** | 设备的唯一标识符（Distinguished Name） |

## 2. HTTP 协议模块用户故事

### US-001: 配置 HTTP 接口

**角色**：测试工程师

**作为**一名测试工程师
**我想要**能够通过 Web 界面配置自定义的 HTTP 接口
**以便**灵活模拟不同网管系统的各种接口，无需修改代码

**验收标准**：
- [ ] 提供 HTTP 接口配置页面，支持配置项包括：
  - 接口路由（path）
  - 请求方法（GET/POST/PUT/DELETE）
  - 认证方式（none/xtoken/basic）
  - 数据源类型（sql/static），默认为 sql
  - 响应模板（JSON 编辑器，支持 `{{items}}`/`{{total}}` 等占位符）
  - 异常模拟（延迟时间、错误码、错误概率）
- [ ] sql 数据源模式：
  - 提供数据集合选择（设备/端口/链路/告警/指标）
  - 选择后自动填充默认 SQL（如 `SELECT * FROM devices`）
  - 链路等需要关联的集合自动填充带 JOIN 的 SQL
  - 提供语法高亮的 SQL 编辑器，可在默认 SQL 基础上自由修改
  - 支持配置 URL 参数到 SQL 命名参数（`:paramName`）的绑定
  - 支持配置分页参数（pageNo/pageSize）
  - 提供「测试执行」按钮，实时预览 SQL 执行结果
- [ ] static 数据源模式：
  - 提供 JSON 编辑器直接填写响应体
  - 支持内置占位符（`{{uuid}}`/`{{random}}`/`{{timestamp}}`）
- [ ] 支持配置多个 HTTP 接口
- [ ] 支持启用/禁用单个接口
- [ ] 接口配置保存后立即生效（动态注册路由，无需重启）
- [ ] 提供 JSON 格式的配置导入/导出功能
- [ ] 支持接口分组管理（按网管系统类型分组）

**优先级**：P0

### US-003: 模拟设备查询接口

**角色**：测试工程师

**作为**一名测试工程师
**我想要**模拟设备查询接口
**以便**测试插件获取设备资源数据的能力

**验收标准**：
- [ ] 数据源使用 SQL 模式，选择「设备」集合后自动填充默认 SQL：
  ```sql
  SELECT * FROM devices
  ```
- [ ] 用户可在默认 SQL 基础上添加过滤和排序条件：
  ```sql
  SELECT * FROM devices
  WHERE (:type IS NULL OR type = :type)
    AND (:status IS NULL OR status = :status)
  ORDER BY name ASC
  ```
- [ ] 配置 URL 参数绑定：type → :type, status → :status
- [ ] 支持自动分页，参数包括 pageNo、pageSize
- [ ] 返回数据包含设备总数和设备列表
- [ ] 通过 SQL 的 `SELECT field AS outputName` 控制输出字段名
- [ ] 支持 3 万+ 设备数据
- [ ] 分页响应时间 < 1 秒（1000条/页）
- [ ] 支持空数据返回场景

**优先级**：P0

### US-004: 模拟告警查询接口

**角色**：测试工程师

**作为**一名测试工程师
**我想要**模拟告警查询接口
**以便**测试插件获取告警数据的能力

**验收标准**：
- [ ] 数据源使用 SQL 模式，选择「告警」集合后自动填充默认 SQL（自动 JOIN 设备表）：
  ```sql
  SELECT a.*, d.name AS deviceName, d.dn AS deviceDn
  FROM alarms a
    JOIN devices d ON a.deviceId = d.id
  ```
- [ ] 用户可添加告警级别、时间范围等过滤条件：
  ```sql
  SELECT a.*, d.name AS deviceName, d.dn AS deviceDn
  FROM alarms a
    JOIN devices d ON a.deviceId = d.id
  WHERE (:level IS NULL OR a.level = :level)
  ORDER BY a.occurTime DESC
  ```
- [ ] 支持自动分页
- [ ] 支持 4 种告警级别（Critical/Major/Minor/Warning）
- [ ] 支持动态生成告警（可配置生成规则）
- [ ] 支持空数据返回场景

**优先级**：P0
