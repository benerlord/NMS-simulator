## 1. 模型总览

拓扑中的所有实体（物理设备、端口、云资源、VM、宿主机、Pod、容器、应用…）统一抽象为 **node**；所有关系（物理链路、包含、部署、依赖…）统一抽象为 **edge**。

### 1.1 核心抽象

| 概念 | 实现 | 说明 |
|------|------|------|
| **节点类型** | `node_types` | 用户可自由定义：switch、router、ecs、hypervisor、pod、container、app …… |
| **节点** | `nodes` | 拓扑中的具体实体 |
| **边类型** | `edge_types` | 用户可自由定义：physical_link、contains、deployed_on、depends_on …… |
| **边** | `edges` | 两节点间的关系 |
| **自定义属性** | `node_attrs` / `edge_attrs` | K-V 存储 |
| **可视化策略** | `node_types.render_mode` + `edge_types` 属性 | 决定画布呈现方式 |

### 1.2 "包含 / 父子"语义

- **不再使用 `parent_id` 列**
- 父子关系表达为一条边：`edge_type.code='contains'`（或 `deployed_on` 等业务语义）
- 通过 `edge_types.exclusive_target = 1` 表示一个节点只能有一条此类入边（即"只能有一个父"）
- 删除节点时**仅删除节点本身及其相连的边**，不递归删除子节点；被解除包含关系的节点会变为孤立节点（顶层节点），可由用户自行处理

### 1.3 节点可视化策略

`node_types.render_mode` 决定一个节点在作为 `contains` 边 target 时的渲染方式：

| 值 | 含义 | 典型场景 |
|----|------|----------|
| `flat` | 作为独立节点平铺在画布上，与父节点之间用实线相连表示包含关系 | 端口、VM、容器、被包含的任何节点 |
| `none` | 顶层节点（不作为任何 contains 边的 target） | 独立设备、独立应用 |

> MVP 阶段不支持 `container`（嵌套容器渲染）与 `anchor`（父节点边缘锚点渲染）两种模式，所有节点一律平铺。`contains` 边与 `physical_link` 等 connect 语义边在画布上视觉一致（均为实线连线），仅通过边类型区分业务语义。

## 3. DDL

### 3.1 拓扑场景

```sql
CREATE TABLE topologies (
  id              TEXT PRIMARY KEY,
  name            TEXT NOT NULL UNIQUE,
  description     TEXT,
  version         INTEGER NOT NULL DEFAULT 1,
  created_at      TEXT NOT NULL DEFAULT (datetime('now')),
  updated_at      TEXT NOT NULL DEFAULT (datetime('now'))
);
```

### 3.2 节点类型

```sql
CREATE TABLE node_types (
  id              TEXT PRIMARY KEY,
  code            TEXT NOT NULL UNIQUE,          -- 英文标识：switch / ecs / pod / container …
  name            TEXT NOT NULL,                 -- 展示名
  category        TEXT NOT NULL,                 -- physical / cloud / application / other（分组展示）
  icon            TEXT,
  color           TEXT,
  shape           TEXT,
  render_mode     TEXT NOT NULL DEFAULT 'none'
                  CHECK (render_mode IN ('none','flat')),
  dn_template     TEXT,                          -- DN 生成模板（如 "NE={id}"）
  description     TEXT,
  created_at      TEXT NOT NULL DEFAULT (datetime('now')),
  updated_at      TEXT NOT NULL DEFAULT (datetime('now'))
);
```

```sql
CREATE TABLE node_type_fields (
  id              INTEGER PRIMARY KEY AUTOINCREMENT,
  node_type_id    TEXT NOT NULL,
  field_key       TEXT NOT NULL,                 -- 英文 key，用于属性存储与 SQL 视图列名
  field_label     TEXT NOT NULL,
  field_type      TEXT NOT NULL CHECK (field_type IN ('text','number','select','boolean')),
  default_value   TEXT,
  options         TEXT,                          -- select 选项 JSON 数组
  required        INTEGER NOT NULL DEFAULT 0,
  sort_order      INTEGER NOT NULL DEFAULT 0,
  FOREIGN KEY (node_type_id) REFERENCES node_types(id) ON DELETE CASCADE,
  UNIQUE (node_type_id, field_key)
);
```

### 3.3 边类型

```sql
CREATE TABLE edge_types (
  id                      TEXT PRIMARY KEY,
  code                    TEXT NOT NULL UNIQUE,  -- physical_link / contains / deployed_on …
  name                    TEXT NOT NULL,
  semantic                TEXT NOT NULL DEFAULT 'connect'
                          CHECK (semantic IN ('connect','contain')),
  -- connect：普通连接关系（物理链路、依赖等）→ 画布画连线
  -- contain：父子/包含关系 → 按目标节点 render_mode 嵌套/锚点/层级线
  directed                INTEGER NOT NULL DEFAULT 1,
  exclusive_target        INTEGER NOT NULL DEFAULT 0,
  -- 1 表示同一 target 节点只能有一条此类入边（用于 contain 语义强制"只能有一个父"）
  allow_source_type_codes TEXT,                  -- JSON 数组；空/NULL=不限
  allow_target_type_codes TEXT,
  line_style              TEXT,                  -- solid / dashed / dotted（connect 专用）
  color                   TEXT,
  description             TEXT,
  created_at              TEXT NOT NULL DEFAULT (datetime('now')),
  updated_at              TEXT NOT NULL DEFAULT (datetime('now'))
);
```

```sql
CREATE TABLE edge_type_fields (
  id              INTEGER PRIMARY KEY AUTOINCREMENT,
  edge_type_id    TEXT NOT NULL,
  field_key       TEXT NOT NULL,
  field_label     TEXT NOT NULL,
  field_type      TEXT NOT NULL CHECK (field_type IN ('text','number','select','boolean')),
  default_value   TEXT,
  options         TEXT,
  required        INTEGER NOT NULL DEFAULT 0,
  sort_order      INTEGER NOT NULL DEFAULT 0,
  FOREIGN KEY (edge_type_id) REFERENCES edge_types(id) ON DELETE CASCADE,
  UNIQUE (edge_type_id, field_key)
);
```

### 3.4 节点

```sql
CREATE TABLE nodes (
  id              TEXT PRIMARY KEY,
  topology_id     TEXT NOT NULL,
  node_type_id    TEXT NOT NULL,
  name            TEXT NOT NULL,
  dn              TEXT,                          -- 可选全局标识
  status          TEXT NOT NULL DEFAULT 'online',
  created_at      TEXT NOT NULL DEFAULT (datetime('now')),
  updated_at      TEXT NOT NULL DEFAULT (datetime('now')),
  FOREIGN KEY (topology_id)  REFERENCES topologies(id) ON DELETE CASCADE,
  FOREIGN KEY (node_type_id) REFERENCES node_types(id)
);
CREATE INDEX idx_nodes_topo          ON nodes(topology_id);
CREATE INDEX idx_nodes_type          ON nodes(node_type_id);
CREATE INDEX idx_nodes_topo_type     ON nodes(topology_id, node_type_id);
CREATE INDEX idx_nodes_status        ON nodes(status);
CREATE UNIQUE INDEX uq_nodes_topo_dn ON nodes(topology_id, dn) WHERE dn IS NOT NULL;
```

```sql
CREATE TABLE node_attrs (
  node_id         TEXT NOT NULL,
  field_key       TEXT NOT NULL,
  value           TEXT,
  PRIMARY KEY (node_id, field_key),
  FOREIGN KEY (node_id) REFERENCES nodes(id) ON DELETE CASCADE
);
CREATE INDEX idx_node_attrs_key ON node_attrs(field_key);
```

### 3.5 边

```sql
CREATE TABLE edges (
  id              TEXT PRIMARY KEY,
  topology_id     TEXT NOT NULL,
  edge_type_id    TEXT NOT NULL,
  source_id       TEXT NOT NULL,
  target_id       TEXT NOT NULL,
  status          TEXT NOT NULL DEFAULT 'up',
  created_at      TEXT NOT NULL DEFAULT (datetime('now')),
  updated_at      TEXT NOT NULL DEFAULT (datetime('now')),
  FOREIGN KEY (topology_id)  REFERENCES topologies(id) ON DELETE CASCADE,
  FOREIGN KEY (edge_type_id) REFERENCES edge_types(id),
  FOREIGN KEY (source_id)    REFERENCES nodes(id) ON DELETE CASCADE,
  FOREIGN KEY (target_id)    REFERENCES nodes(id) ON DELETE CASCADE,
  CHECK (source_id <> target_id)
);
CREATE INDEX idx_edges_topo      ON edges(topology_id);
CREATE INDEX idx_edges_type      ON edges(edge_type_id);
CREATE INDEX idx_edges_src       ON edges(source_id);
CREATE INDEX idx_edges_tgt       ON edges(target_id);
CREATE INDEX idx_edges_topo_type ON edges(topology_id, edge_type_id);
```

> **"只能有一个父"约束**：对 `edge_types.exclusive_target = 1` 的边，应用层保证同一 `(edge_type_id, target_id)` 最多一条记录。也可在数据库层加触发器，但 MVP 阶段以应用层校验为准。

```sql
CREATE TABLE edge_attrs (
  edge_id         TEXT NOT NULL,
  field_key       TEXT NOT NULL,
  value           TEXT,
  PRIMARY KEY (edge_id, field_key),
  FOREIGN KEY (edge_id) REFERENCES edges(id) ON DELETE CASCADE
);
CREATE INDEX idx_edge_attrs_key ON edge_attrs(field_key);
```

### 3.6 画布节点

MVP 阶段所有节点都平铺在画布上，每个节点都有独立坐标。

```sql
CREATE TABLE canvas_nodes (
  node_id         TEXT PRIMARY KEY,
  topology_id     TEXT NOT NULL,
  x               REAL NOT NULL DEFAULT 0,
  y               REAL NOT NULL DEFAULT 0,
  FOREIGN KEY (node_id)     REFERENCES nodes(id) ON DELETE CASCADE,
  FOREIGN KEY (topology_id) REFERENCES topologies(id) ON DELETE CASCADE
);
CREATE INDEX idx_canvas_topo ON canvas_nodes(topology_id);
```

画布全局状态（zoom、offset）以 `settings` 表键 `canvas_state:<topology_id>` 存储。

### 3.7 接口配置

```sql
CREATE TABLE api_configs (
  id              TEXT PRIMARY KEY,
  name            TEXT NOT NULL,
  method          TEXT NOT NULL,                 -- GET/POST/PUT/DELETE/PATCH
  path            TEXT NOT NULL,
  enabled         INTEGER NOT NULL DEFAULT 1,
  group_name      TEXT,
  data_source     TEXT NOT NULL CHECK (data_source IN ('sql','static')),
  topology_id     TEXT,                          -- sql 模式必填；static 可空
  sql_text        TEXT,                          -- sql 模式使用
  config          TEXT NOT NULL,                 -- JSON：auth/params/pagination/response/fault/staticBody
  created_at      TEXT NOT NULL DEFAULT (datetime('now')),
  updated_at      TEXT NOT NULL DEFAULT (datetime('now')),
  FOREIGN KEY (topology_id) REFERENCES topologies(id),
  UNIQUE (method, path)
);
CREATE INDEX idx_apis_enabled ON api_configs(enabled);
CREATE INDEX idx_apis_topo    ON api_configs(topology_id);
CREATE INDEX idx_apis_group   ON api_configs(group_name);
```

业务约束（应用层）：
- `data_source='sql'` 时 `topology_id` 与 `sql_text` 必填
- 删除 `topologies` 前若存在引用，阻止删除（不设 ON DELETE CASCADE）

### 3.8 Token

> Token 注册表，服务于 Pipeline 的 `_step3_authenticate` 校验阶段。ManageOne / eSight 等系统的鉴权接口（如 `POST /rest/manage/user/login`）本身由用户在接口配置中模拟，Token 颁发后由工程师手动录入本表。Pipeline 据此判断请求携带的 Token 是否有效（存在、未撤销、未过期）。

```sql
CREATE TABLE tokens (
  token           TEXT PRIMARY KEY,
  issued_at       TEXT NOT NULL DEFAULT (datetime('now')),
  expires_at      TEXT NOT NULL,
  revoked         INTEGER NOT NULL DEFAULT 0,
  issued_by_api   TEXT,
  meta            TEXT
);
CREATE INDEX idx_tokens_exp ON tokens(expires_at);
```

### 3.9 系统设置

```sql
CREATE TABLE settings (
  key             TEXT PRIMARY KEY,
  value           TEXT NOT NULL,
  updated_at      TEXT NOT NULL DEFAULT (datetime('now'))
);
```

## 4. 语义表达示例

| 业务场景 | 表达 |
|----------|------|
| 交换机包含端口 | `contains` 边：source=switch, target=port；port 的 `render_mode='flat'`，画布上实线相连 |
| 宿主机运行 VM | `contains` 边（或自定义 `deployed_on` 边）：source=hypervisor, target=vm；vm 的 `render_mode='flat'` |
| Pod 包含容器 | `contains` 边：source=pod, target=container；container 的 `render_mode='flat'` |
| 两端口间物理链路 | `physical_link` 边（semantic=connect）：source=port_a, target=port_b |
| 应用依赖数据库 | `depends_on` 边（semantic=connect）：source=app, target=db |
| 容器连接到某服务 | `connects` 边（semantic=connect）：source=container, target=service |

## 5. SQL 模式：动态视图生成

用户在接口的 SQL 编辑器中，希望像"每类一张表"一样写查询。执行前系统自动按绑定拓扑的类型拼接 CTE：

```sql
-- 系统自动注入（示例）
WITH
  -- 通用基础视图
  nodes AS (SELECT * FROM nodes WHERE topology_id = :__tid__),
  edges AS (SELECT * FROM edges WHERE topology_id = :__tid__),

  -- 每个节点类型一个同名 CTE：固定字段 + 打平自定义属性
  switches AS (
    SELECT n.id, n.name, n.dn, n.status,
           MAX(CASE WHEN a.field_key='vendor' THEN a.value END) AS vendor,
           MAX(CASE WHEN a.field_key='model'  THEN a.value END) AS model,
           MAX(CASE WHEN a.field_key='ip'     THEN a.value END) AS ip
    FROM nodes n LEFT JOIN node_attrs a ON a.node_id=n.id
    WHERE n.topology_id=:__tid__
      AND n.node_type_id=(SELECT id FROM node_types WHERE code='switch')
    GROUP BY n.id
  ),
  ports AS ( ... ),
  ecs   AS ( ... ),
  pods  AS ( ... ),

  -- 每个边类型一个同名 CTE
  physical_links AS (
    SELECT e.id, e.source_id, e.target_id, e.status,
           s.name AS source_name, s.dn AS source_dn,
           t.name AS target_name, t.dn AS target_dn
    FROM edges e
    JOIN nodes s ON s.id=e.source_id
    JOIN nodes t ON t.id=e.target_id
    WHERE e.topology_id=:__tid__
      AND e.edge_type_id=(SELECT id FROM edge_types WHERE code='physical_link')
  ),

  -- 便捷"父子"视图（基于 contain 语义的边）
  children AS (
    SELECT e.source_id AS parent_id, n.*
    FROM edges e
    JOIN edge_types et ON et.id=e.edge_type_id AND et.semantic='contain'
    JOIN nodes n ON n.id=e.target_id
    WHERE e.topology_id=:__tid__
  )
-- 用户 SQL 直接写：
SELECT * FROM switches WHERE vendor='华为';
SELECT * FROM physical_links;
SELECT * FROM children WHERE parent_id=:pid;
```

**生成规则**：
- 每次接口被调用时，根据绑定拓扑拥有的 `node_types` / `edge_types` 动态生成对应 CTE
- CTE 名即类型 `code`（用户自定义时需保证符合 SQL 标识符规范且不冲突）
- 字段 = 固定列 + 按 `node_type_fields` 展开的属性列
- 永远注入 `nodes` / `edges` / `children` 三个通用 CTE

## 6. 数据生命周期

| 对象 | 创建 | 更新 | 删除行为 |
|------|------|------|----------|
| 拓扑 | 新建拓扑 | 编辑即写库 | 被接口绑定则阻止删除；否则级联删除其节点 / 边 / 画布 |
| 节点 | 画布拖入 / API 创建 | 编辑属性 | **仅删除节点本身**；外键级联删除 `node_attrs`、`canvas_nodes`、以及以该节点为 source 或 target 的所有 `edges`（及其 `edge_attrs`）；**不递归删除子节点**，子节点变为孤立节点 |
| 边 | 画布连线 / API 创建 | 编辑属性 | 仅删除边本身；外键级联删除 `edge_attrs`；**不删除两端节点** |
| 节点类型 / 边类型 | 全局管理页面 | 编辑 | 若被节点 / 边引用则阻止删除 |
| 接口 | 新建 | 编辑即写库并同步路由 | 直接删除 + 卸载路由 |
| Token | 用户手动录入注册表（mock 接口模拟颁发） | 过期自动失效 / 手动撤销 | `DELETE /admin/api/tokens/expired` 手动清理 |

## 10. 与 v1.0 的主要变更

| 变更 | 说明 |
|------|------|
| 取消 `devices` / `ports` / `links` 三张专表 | 统一为 `nodes` + `edges` |
| 取消 `nodes.parent_id` | 父子关系用 `contain` 语义的边表达 |
| 新增 `node_types.render_mode` | 决定节点在被包含时的可视化方式（container / anchor / flat / none） |
| 新增 `edge_types.semantic` | 区分"连接"与"包含"两类边 |
| 新增 `edge_types.exclusive_target` | 强制"只能有一个父"约束（应用层执行） |
| 新增 `edge_type_fields` / `edge_attrs` | 支持边的自定义属性 |
| 新增预置节点类型 / 边类型 | 覆盖物理 / 云 / 应用三层常见概念 |
