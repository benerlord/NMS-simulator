  - 后端 Python 3.11+ + FastAPI + Pydantic v2 + SQLite

  - 模块划分、SQLite 表清单、请求处理管道、动态路由同步、目录结构与 `.env` 配置

- **数据库表设计**（`数据库表设计.md` v1.0）
  - 13 张表 DDL：拓扑 / 历史 / 设备类型 / 设备 / 属性 / 端口 / 链路 / 画布 / 接口 / Token / 日志 / 设置
  - 采用扁平关系表（非 JSON blob），固定字段存列、自定义属性 K-V 存副表
  - 接口配置仅 `method/path/enabled/topology_id/sql_text` 上列，嵌套结构进 `config` JSON
  - 明确外键级联与业务层删除约束（拓扑被接口引用时阻止删除）
  - 索引策略 + SQL 模式视图隔离方案（拓扑作用域内查询）
  - 请求日志滚动 10000 条；历史版本保留 3 个

- **数据库表设计 v2.0**（重构）
  - 放弃 devices / ports / links 专表，采用**统一节点 + 统一边**模型，覆盖物理 / 云 / 应用三层
  - 取消 `parent_id`，父子关系用 `contain` 语义的边表达，通过 `edge_types.exclusive_target` 约束"只能有一个父"
  - `node_types.render_mode` 决定可视化方式：container（嵌套）/ anchor（父节点锚点）/ flat（层级线）/ none
  - 新增 15 张表：含 `node_types/node_type_fields/edge_types/edge_type_fields/nodes/node_attrs/edges/edge_attrs` 等
  - SQL 模式改为**动态 CTE 视图生成**：按绑定拓扑中出现的类型，每类型一个同名视图（字段=固定列+属性打平）；始终提供 `nodes/edges/children` 通用视图
  - 预置 11 个节点类型（交换机 / 路由器 / ECS / 宿主机 / Pod / 容器……）与 5 个边类型（contains / physical_link / deployed_on / depends_on / connects）

- **API 接口设计**（`API接口设计.md` v1.0）
  - 三通道划分：`/admin/api/**`（管理）、`/admin/ws`（实时）、`/mock/**`（模拟）
  - 管理 API 覆盖 11 个模块：拓扑 / 节点类型 / 边类型 / 节点 / 边 / 接口配置 / SQL 辅助 / Token / 日志 / 系统设置 / 仪表盘
  - 统一响应结构、错误码分段、前端 camelCase + 服务层 snake_case 映射
  - 节点批量创建支持自动建 parent 边；画布位置单独 PATCH 接口
  - 接口配置含测试执行（不计日志） + 启用开关 / 拓扑切换 PATCH
  - SQL 辅助：动态 CTE 视图清单、预览、直接执行
  - WebSocket 订阅模型 + 7 类事件 + ping/pong 心跳
