- **数据库列** `snake_case`；**API 字段** `camelCase`；**服务层** 在 `serializers` 做一次映射，不允许 camelCase 泄漏到 DB 层。

- **错误码** 统一 `app/core/errors.py`，按模块段（401xx / 402xx / 403xx / 404xx / 5xxxx）集中定义。

### 1.3 Git 约定

- 分支：`main`（可运行）/ `feat/<模块>` / `fix/<简述>`
- Commit 前缀：`feat` / `fix` / `refactor` / `docs` / `chore`
- 每个 PR 关联一个任务编号（见第 4 章 WBS）
- 合并前必须：后端 `pytest` 通过 + 前端 `pnpm build` 通过

## 2. 关键技术实现方案

### 2.1 动态路由注册（/mock/**）

- **方案**：FastAPI 启动时加载 `api_configs` 全表，为每条 `enabled=1` 的记录调用 `app.add_api_route`；运行时增删改通过 `RouteRegistry` 维护 `app.router.routes` 列表。
- **关键点**：path 参数（`/devices/{id}`）用 FastAPI 原生占位；method/path 变更走"卸载旧 + 注册新"；enable 开关不动路由，在管道 [2] 步 404。
- **验收**：新增接口后 < 200ms 可被 `curl /mock/**` 命中；禁用后立即返回 404；method 变更后旧 method 返回 405。

### 2.2 动态 CTE 视图生成（SQL 模式）

- **输入**：绑定拓扑 id + 用户 SQL。
- **流程**：
  1. 查询该拓扑下出现的所有 `node_type_id` 与 `edge_type_id`
  2. 为每个类型生成一个 `WITH <code> AS (SELECT 固定列 + 属性打平 FROM nodes JOIN node_attrs ...)` CTE
  3. 始终附加 `nodes / edges / children` 三个通用 CTE
  4. 拼接 `WITH ...所有 CTE... <用户 SQL>`
- **验收**：用户写 `SELECT * FROM switches WHERE vendor='华为'` 能直接返回；自定义属性字段自动出现在对应视图列中；绑定拓扑切换后视图列随之变化。

### 2.3 SQL 白名单校验

- **规则**：去除首部 `--` / `/* */` 注释与空白后，首关键字必须是 `SELECT` 或 `WITH`（大小写不敏感）。
- **实现**：`app/core/sql_executor.py::validate_readonly(sql) -> None | raise`
- **验收**：`INSERT` / `UPDATE` / `DELETE` / `DROP` / `ATTACH` / `PRAGMA` 全部拒绝并返回 40301；多语句（含 `;`）拒绝。

### 2.4 参数绑定与自动分页

- URL query 参数 → 按配置 `param_mapping` 映射为命名参数 `:paramName`
- 分页：`SELECT COUNT(*) FROM (<用户 SQL>) _t` 得 total；再 `<用户 SQL> LIMIT :pageSize OFFSET :offset` 取页
- **验收**：`?page=2&pageSize=20` 生效；total 正确；缺失参数用配置默认值；类型转换失败返回 40302。

### 2.5 响应模板渲染

- 占位符：`{{items}}` / `{{total}}` / `{{page}}` / `{{pageSize}}` / `{{uuid}}` / `{{now}}`
- 实现：简单字符串替换 + `json.loads` 验证结构，不引入 Jinja（避免过度工程）
- **验收**：模板非法 JSON 返回 40303；`{{items}}` 被替换为 SQL 结果数组；嵌套模板可用。

### 2.6 Token 认证模拟

- 三种 auth 类型：`none` / `xtoken`（header `X-Auth-Token`）/ `basic`（header `Authorization: Basic ...`）
- xtoken 校验 `tokens` 表 `expires_at > now AND revoked = 0`
- **验收**：无 token 返回 40401；过期 token 返回 40402；手动失效 token 返回 40403；basic 错误返回 40404。

### 2.7 自动保存（60s）

- 前端 `topologyStore` 维护 `dirty` 标志；60s 定时器 + 退出前 `beforeunload` 提示
- 后端收到保存请求 → 事务写 `nodes/edges/node_attrs/edge_attrs/canvas_nodes` → WS 推 `topology.saved`
- **验收**：60s 内无操作自动触发；保存成功前端角标由"未保存"→"已保存 HH:MM"；网络失败时角标红色提示"保存失败（重试中）"。

### 2.8 WebSocket 推送

- 单一连接 `/admin/ws`；订阅模型：客户端发 `{op:'subscribe', topics:['log.request','topology.saved']}`
- 心跳：ping/pong 30s
- **验收**：7 类事件按订阅投递；断线自动重连（前端）；1000 条/s 日志事件下不丢包（后端用 asyncio.Queue 背压）。

### 2.9 请求日志滚动

- 每次 `/mock/**` 请求结束后 `INSERT INTO request_logs`；插入后若 `COUNT(*) > 10000`，删除最旧的 `COUNT - 10000` 条
- 为避免每请求都 COUNT，改为每 100 次请求触发一次清理
- **验收**：10500 条请求后表内稳定 ≤ 10000；清理不阻塞请求响应（异步任务）。

### 2.10 画布性能（3 万节点）

- **AntV X6 优化**：开启 `async: true`、`frozen: true`（大图模式）；节点用 HTML 节点改为 SVG 形状；超过 500 节点时关闭动画
- **数据加载**：`GET /topologies/{id}/graph` 一次性返回全图 JSON（< 10MB for 3 万节点）；前端本地过滤
- **验收**：3 万节点加载 < 3s；拖动单节点 60fps；缩放/平移不卡顿。

## 6. 风险与应对（MVP 关注项）

| 风险 | 影响 | 应对 |
|------|------|------|
| SQLite 并发写入瓶颈 | 自动保存 + 日志写入冲突 | 单写线程 + WAL 模式（`PRAGMA journal_mode=WAL`） |
| 动态 CTE 拼接出错 | SQL 模式不可用 | 每个 node_type 生成时单元测试覆盖；失败回退为 `SELECT * FROM nodes` |
| 3 万节点画布卡顿 | 用户体验崩溃 | X6 `frozen` + 视口外节点不渲染；必要时降级为列表视图 |
| 动态路由与 FastAPI OpenAPI 冲突 | /docs 异常 | `/mock/**` 路由设 `include_in_schema=False` |
| Windows 路径/编码问题 | 启动失败 | 所有文件 IO 强制 UTF-8；路径用 `pathlib.Path` |
