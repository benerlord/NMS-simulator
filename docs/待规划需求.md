## 1. 节点类型字段展示和添加优化

### 现状

类型管理 → 节点类型 → 展开行 → 字段编辑器（`NodeTypeFieldEditor.vue`）中，字段以表格行形式展示，通过弹窗逐个添加/编辑。当前交互存在以下问题：

- **字段多时不直观** — 列表中仅显示字段标识、类型等少数列，字段之间的关联和整体结构不清晰
- **添加流程繁琐** — 每次添加一个字段需要：点"添加字段" → 弹窗 → 填表单 → 确定，批量添加字段效率低
- **字段顺序调整困难** — sortOrder 通过数字输入调整，拖拽排序更直观
- **缺少批量操作** — 无法批量删除、批量修改字段类型等

### 待规划方向

| 方向 | 说明 |
|------|------|
| 字段表格内联编辑 | 在表格行内直接编辑字段属性，减少弹窗操作 |
| 批量添加字段 | 支持一次添加多个字段（如从 Excel 列头粘贴） |
| 拖拽排序 | 字段列表支持拖拽调整 sortOrder |
| 字段预览 | 新增时实时预览该类型节点在画布上的属性面板效果 |
| 字段模板 | 预设常用字段组合模板，一键导入（如网络设备通用字段） |
