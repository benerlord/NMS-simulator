# 节点组 — 前端用户使用逻辑

## 入口

从画布页面的**左侧 TypePalette** 进入。在现有"节点类型"面板下方新增一个"节点组"区域。

```
┌──────────────────────────────┐
│  节点类型              [展开] │
│  ┌──────────────────────┐    │
│  │ 交换机  SW           │    │
│  │ 路由器  RT           │    │
│  │ 服务器  SRV          │    │
│  │ ...                  │    │
│  └──────────────────────┘    │
│                              │
│  节点组                [+ 新建] │
│  ┌──────────────────────┐    │
│  │ 🟢 Spine 交换机 ×100 │    │
│  │ 🟢 Leaf 交换机 ×480  │    │
│  │ ⚪ 机架服务器 ×10000 │    │  ← 尚未展开
│  │ 🟢 宿主机 ×200       │    │
│  └──────────────────────┘    │
└──────────────────────────────┘
```

| 状态 | 含义 |
|------|------|
| 🟢 绿色圆点 | 已展开（materialized），画布上存在实体节点 |
| ⚪ 灰色圆点 | 未展开，仅存组定义，画布上不可见 |

## 流程一：创建节点组

### 步骤 1：点击 [+ 新建]

弹出创建表单（Modal），三步骤：

```
╔═══════════════════════════════════╗
║  新建节点组                  [×]  ║
╠═══════════════════════════════════╣
║                                   ║
║  【步骤 1/3：基础信息】             ║
║                                   ║
║  选择类型    [交换机        ▼]     ║
║  组名称      [Spine 交换机____]    ║
║  节点数量    [100________]         ║
║                                   ║
║  命名规则                          ║
║  前缀        [SPINE-________]      ║
║  编号格式    [数字补零 5位  ▼]     ║
║  预览        SPINE-00001          ║
║              SPINE-00002          ║
║              ...                  ║
║              SPINE-00100          ║
║                                   ║
║               [下一步]             ║
╚═══════════════════════════════════╝
```

### 步骤 2：属性生成策略

```
╔═══════════════════════════════════╗
║  新建节点组                  [×]  ║
╠═══════════════════════════════════╣
║                                   ║
║  【步骤 2/3：属性策略】             ║
║                                   ║
║  ┌─ vendor（厂商）─────────────┐  ║
║  │ 策略  [随机选取        ▼]   │  ║
║  │ 候选值                      │  ║
║  │ ┌──────────┬──────┬─────┐  │  ║
║  │ │ Huawei   │ ×    │     │  │  ║
║  │ │ Cisco    │ ×    │     │  │  ║
║  │ │ H3C      │ ×    │     │  │  ║
║  │ │ + 添加    │      │     │  │  ║
║  │ └──────────┴──────┴─────┘  │  ║
║  └────────────────────────────┘  ║
║                                   ║
║  ┌─ ip（IP地址）───────────────┐  ║
║  │ 策略  [递增            ▼]   │  ║
║  │ 起始值  10.0.0.1           │  ║
║  │ 步长    1                  │  ║
║  │ 预览    10.0.0.1           │  ║
║  │         10.0.0.2           │  ║
║  │         10.0.0.3 ...       │  ║
║  └────────────────────────────┘  ║
║                                   ║
║  ┌─ model（型号）──────────────┐  ║
║  │ 策略  [固定值         ▼]    │  ║
║  │ 值    CE6800-48S6CQ       │  ║
║  └────────────────────────────┘  ║
║                                   ║
║  [+ 添加属性]                     ║
║                                   ║
║       [上一步]       [下一步]      ║
╚═══════════════════════════════════╝
```

属性字段自动从该 `node_type` 的 `fields` 中读取（如交换机有 vendor、model、ip 三个字段），用户逐一配置。

**策略类型**：

| 策略 | UI 配置 | 示例结果 |
|------|--------|---------|
| 固定值 | 一个输入框 | 所有节点 model = "CE6800" |
| 随机选取 | 候选值列表（可增删） | vendor 随机取 Huawei/Cisco/H3C |
| 递增 | 起始值 + 步长 | ip = 10.0.0.1, 10.0.0.2, ... |
| 范围随机 | min + max | cpu = 随机 4~64 |

### 步骤 3：连接规则（可选）

```
╔═══════════════════════════════════╗
║  新建节点组                  [×]  ║
╠═══════════════════════════════════╣
║                                   ║
║  【步骤 3/3：连接规则】             ║
║                                   ║
║  如何连接到其他节点（组）？          ║
║                                   ║
║  ┌─ 规则 1 ────────────────────┐  ║
║  │ 目标       [Leaf 交换机 ▼]   │  ║
║  │ 边类型     [物理链路   ▼]    │  ║
║  │ 模式       [全连接     ▼]    │  ║
║  │         每个 Spine 连 全部 Leaf│  ║
║  │         预期边数: 100×480    │  ║
║  │         = 48,000 条         │  ║
║  └─────────────────────────────┘  ║
║                                   ║
║  ┌─ 规则 2 ────────────────────┐  ║
║  │ 目标       [机架服务器 ▼]     │  ║
║  │ 边类型     [物理链路   ▼]    │  ║
║  │ 模式       [取模分配   ▼]    │  ║
║  │ 比例       每 [1] 源 连 [48] 目标│
║  │ 预览       Leaf#1 → 1~48     │  ║
║  │            Leaf#2 → 49~96    │  ║
║  │            Leaf#3 → 97~144   │  ║
║  │ 预期边数: 480×48 = 23,040 条 │  ║
║  └─────────────────────────────┘  ║
║                                   ║
║  [+ 添加连接规则]                  ║
║                                   ║
║      [上一步]       [完成创建]      ║
╚═══════════════════════════════════╝
```

**连接模式**：

| 模式 | 预览时显示的说明 |
|------|----------------|
| 全连接 | "每个 A 连接全部 B → N×M 条边" |
| 取模分配 | "每 K 个 A 连 1 个 B → N×K 条边" |
| 一对一 | "按序号 1-1 配对 → min(N,M) 条边" |
| 一对多 | "每个 A 连 K 个 B → N×K 条边" |

## 流程二：展开节点组

用户在左侧面板点击某个节点组（如"机架服务器 ×10000"），弹出操作菜单：

```
┌─────────────────────┐
│ 机架服务器 ×10000    │
│ ⚪ 未展开            │
│                     │
│ [🚀 展开到画布]      │
│ [✏️ 编辑组定义]      │
│ [🗑 删除组]          │
└─────────────────────┘
```

点击"展开到画布"：

1. **确认弹窗**：

```
╔═══════════════════════════════════╗
║  确认展开节点组                    ║
╠═══════════════════════════════════╣
║                                   ║
║  即将生成：                        ║
║  • 10,000 个 机架服务器 节点        ║
║  • 23,040 条 物理链路 边           ║
║  • 48,000 条 物理链路 边           ║
║                                   ║
║  预计耗时约 2~3 分钟               ║
║                                   ║
║           [取消]    [确认展开]      ║
╚═══════════════════════════════════╝
```

2. **进度条**（底部或 Modal 内）：

```
展开中...  节点 6,320 / 10,000  [████████░░░░] 63%
           边    28,000 / 71,040
```

进度通过 WebSocket 实时推送。

3. **完成后**：
   - 该组的圆点变 🟢 绿色
   - 画布自动缩放至 Fit 视图（展示全部新节点）
   - 消息提示 "已展开 10,000 个节点、71,040 条边，耗时 2 分 18 秒"

## 流程三：画布上与节点组的交互

展开后，节点组内的节点在画布上以**组为单位**管理：

### 3.1 画布右侧 — 图层面板

```
┌────────────────────┐
│ 图层               │
│                    │
│ ☑ 🟢 Spine 交换机    │  ← 勾选 = 高亮
│ ☑ 🟢 Leaf 交换机     │     取消 = 隐藏
│ ☑ 🟢 机架服务器      │
│ ☐ 🟢 宿主机         │
│                    │
│ [全选] [取消全选]   │
└────────────────────┘
```

- 勾选/取消 → 画布上该组全部节点同步显示/隐藏
- 点击组名 → 画布缩放到该组的包围盒区域

### 3.2 画布布局

展开后在画布上自动排列。提供三种布局方式：

| 布局 | 表现 | 适用 |
|------|------|------|
| 网格 | 节点按网格排列，组与组之间留间距 | 默认、直观 |
| 力导 | 用力导向算法自动分布 | 适合观察连接关系 |
| 分层 | 按组间连接规则分层排列（如 Spine 层→Leaf 层→服务器层） | 三层网络结构 |

布局在节点组的右键菜单中触发：

```
┌─────────────────────┐
│ Spine 交换机组       │
│                     │
│ [网格排列]          │
│ [力导分布]          │
│ [分层排列]          │
│ ──────────          │
│ [🔍 缩放到此组]      │
│ [👁 仅显示此组]      │
│ [🚀 重新展开]        │
│ [🗑 删除此组]        │
└─────────────────────┘
```

### 3.3 单个节点操作

展开后的节点就是普通节点——可点击查看属性、拖拽移动、手动连线、单独删除。与手动创建的节点行为一致，唯一的区别是多了一个 `groupId` 属性标记来源。

---

## 流程四：编辑和重新展开

1. 用户在左侧面板点击"编辑组定义"
2. 打开与创建时相同的三步表单，预填当前配置
3. 修改参数后点击保存：

```
╔═══════════════════════════════════╗
║  已展开的节点组无法直接修改属性     ║
║                                   ║
║  选择操作：                        ║
║  [仅保存定义] — 保存新配置但不影响    ║
║                已有节点             ║
║  [重新展开]   — 删除旧节点后用新    ║
║                配置重新生成          ║
║                                   ║
║           [取消]                   ║
╚═══════════════════════════════════╝
```

---

## 流程五：删除节点组

- **未展开的组**：直接删除组定义
- **已展开的组**：确认弹窗 → "这将同时删除画布上的 N 个节点和 M 条边" → 确认后级联删除
